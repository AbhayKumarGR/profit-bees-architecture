# Technology Decisions

## Current baseline

| Area | Technology / Decision |
|---|---|
| Frontend | Next.js + TypeScript |
| Backend | Spring Boot 3.x + Java 21 |
| Database | PostgreSQL on Cloud SQL |
| Cache / events | Redis on Memorystore |
| Runtime | Docker containers on Cloud Run |
| Container registry | Artifact Registry |
| CI/CD | Cloud Build / Cloud Deploy |
| Secrets | Secret Manager |
| Scheduling | Cloud Scheduler |
| Observability | Cloud Monitoring, Cloud Logging, Cloud Trace, Micrometer, OpenTelemetry |
| AI | OpenAI Responses API, invoked on demand only |
| Business time | Centralized Time Service using Asia/Kolkata |
